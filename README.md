# Reference

- `fmt.Print()` takes multiple args and prints them sequentially
- `fmt.Println()` prints with no formatting, separates different values with spaces and ends with a newline
- `fmt.Printf()` prints with default formatting
- `var variable_name type` outside any function
- no parens in conditionals and loops but braces are required always
